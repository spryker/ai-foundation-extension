# AiFoundationExtension Module
[![Latest Stable Version](https://poser.pugx.org/spryker/ai-foundation-extension/v/stable.svg)](https://packagist.org/packages/spryker/ai-foundation-extension)
[![Minimum PHP Version](https://img.shields.io/badge/php-%3E%3D%208.3-8892BF.svg)](https://php.net/)

The module provides plugin interfaces for extending AiFoundation module functionality: AI tools with their parameters for the Client layer.

## Installation

```
composer require spryker/ai-foundation-extension
```
